A shift on the IAM desk

Labs arrive the way work does: as tickets, emails and alerts. Nothing tells you which ones are traps.

  1. A ticket lands in your queue

    A charge nurse starts Monday, a radiographer transfers, a contractor's end date passed last week. Some requests are urgent. Some are not what they say they are.

  2. You check it against the source of truth

    PeopleHub says who works here, in which role, for whom. The access policy says what that role gets. "Copy her colleague's access" is not a justification under minimum necessary.

  3. You make the change

    In ADUC, in PowerShell, in the Entra admin center or the Okta console, whichever the job calls for. Disable before you remove. Revoke sessions when someone is walked out.

  4. The lab grades what actually happened

    Checks read the directory, the cloud tenants and the ticket, not your intentions. Fall for a trap and Copilot tells you which control just broke.

A mentor that watches the lab, not just the chat

IAM Copilot re-checks every running lab after each change you make. If you disable the wrong nurse or add a service account to Domain Admins, it tells you straight away, the way a senior colleague looking over your shoulder would.

Chat runs on your own computer through Ollama with llama3.2. It never decides whether you passed: the checks do. Without Ollama, the monitor still works and the chat falls back to what the checks say.

Install in a couple of minutes

Your world, settings and progress are saved on your computer and kept through updates.

  1. Download the installer

    Meridian IAM Range Setup for Windows 10 or 11, 64-bit.

  2. Run it

    The installer is not code-signed yet, so Windows SmartScreen may stop it. Choose More info, then Run anyway. You can install for your account only, without administrator rights.

  3. Sign in as Admin

    The default password is shown on the sign-in screen: Meridian!2026. Open IAM Coach on the desktop and start your first lab.

Automatic updates. The app checks for new releases when it starts and every six hours, downloads them in the background, and installs them when you restart. Settings > Windows Update shows the current version and status.

Optional AI. Install Ollama and run ollama pull llama3.2 to turn on Copilot chat, AI-designed labs and reworded tickets.

Rather not install? Open the web edition. It is the same lab in your browser; progress stays in that browser, and Copilot chat needs Ollama to allow the site (setx OLLAMA_ORIGINS "https://this-site", then restart Ollama). Allow only this site, never "*", which would let any website use your local model.

Prefer the source? Clone the repository and run npm ci then npm run dev in range/.

Meridian IAM Range is a training environment. Meridian Health System, its staff, patients, domains and applications are fictional. It does not connect to or change any real directory or tenant.
